小于的436背书法：先关书讲出来，再算“学会”

这是按你现在的起点定制的首版：9月10日从零开始、非本专业、每天最多5个新内容单元、周日只回收。课内只刷数学，不背436；436放在安静自习格理解、回家后出声复述。目标不是“看着眼熟”，而是考场上能独立组织答案。

唯一完成标准关书能说，落笔能写翻着书顺下来、反复划线、只看懂，都不计完成。
01
记忆线概念、程序、准则、报告：先抓答题顺序，再抓关键词。
02
计算线方法适用性、公式、参数、步骤、单位和结论一起写。
03
表达线每次都说清方法选择、前提假设、结果与风险，不只报数字。
每日闭环
5个新内容，必须走完四步
  1. 1
    搭骨架，不抄全文

    把每个标题改成一道问题；只写“答题顺序 + 3–5个关键词”。先知道它在本章解决什么问题，再记细节。

  2. 2
    关书出声，暴露断点

    在家或安静处看问题后合书作答。约10秒仍开不了头就直接记C，不边看边背，也不靠熟悉感放行。

  3. 3
    对照补洞，只改漏点

    打开原文核对，把缺失关键词、逻辑顺序和限定条件补在框架旁；随后立刻再关书说一遍，不从头抄答案。

  4. 4
    按当天课表落笔

    短答、论述或计算按当天已排的量完整手写。写完检查：术语是否准确、步骤是否齐、单位是否漏、结论是否回应题目。

A

A：能独立讲完整结构正确，关键词和限定条件基本齐；才可记为“已背”。

B

B：能讲框架但漏关键点当天补一次，次日优先抽查；不能冒充完成。

C

C：关书后无法开口退回章节框架重新理解，下一次436学习格先处理。

复习节奏
同一内容默认回访4次

当天 → 次日 → 第3天 → 第7天

  • 每次先关书，不先重读。
  • A只快速抽查；B/C优先复述与落笔。
  • 这是默认回访点，不是死公式；欠账多时以清B/C为先。

章末：一页章节框架 → 已核对的辽大436真题 → 对照补答题语句。没有核对过的题号不编。

与你的课表对齐
地点决定训练方式
  • 安静自习格：理解当天5个、压成框架。
  • 回家晚间格：出声闭卷复述，再补漏点。
  • 下一次436格：先抽前一天B/C，再开新内容。
  • 周日：不添新账，只做本周抽查、短答或计算验收。
考场输出模板
背的时候，就按答案将来要写出的样子背
名词解释

所属对象/类别 → 核心含义 → 适用条件或边界 → 在评估中的作用。

简答 / 论述

一句话总述 → 分点写3–5层逻辑 → 补方法、条件或影响 → 回扣题目作结。

计算题

判断方法与适用性 → 列已知和公式 → 带单位代入 → 验算合理性 → 写结论及风险提示。

防止假进度
卡住时不加量，先把欠账关掉
  • 当天5个里有3个及以上为C：下一段436时间先清欠账，再开新内容；没清完就如实顺延。
  • 不因为焦虑把5个提高到10个，也不挤00:00睡眠边界；未通过闭卷输出的内容不记“已背”。
  • 每天只留一行证据：日期｜新内容1–5｜A/B/C｜最大缺口｜下次回访日｜手写输出。

先照此法连续执行7天后再按真实结果调整：看A/B/C数量、最常漏的类型和手写完成情况，只改一个变量。它是你当前条件下最合适的可验证首版，不是“保证上岸”的承诺。
