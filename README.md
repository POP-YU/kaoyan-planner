# 小于的考研课表

> **换 AI / 交接必读**：[`AGENTS.md`](AGENTS.md) —— 项目规则、代码地图、验证与发布流程都在里面。任何 AI 接手前先完整读它。

一个公开的静态考研课表。打开页面后，它会按设备本地日期只展示**当天**的完整时间表；顶部时钟按秒走，早餐按日期轮换，下面接着是按月份划分的阶段路线。它不需要登录、后端或云端同步。

## iPhone 安装（描述文件 / 主屏幕图标）

1. 用 iPhone 的 **Safari**（不要用微信/QQ 内置浏览器）打开 **https://pop-yu.github.io/kaoyan-planner/kaoyan.mobileconfig** → 会弹出“网站正尝试下载配置描述文件”→ 允许 → 提示“描述文件已下载”。
2. 打开 **设置 App**，首页 Apple ID 那一栏下方会出现“**已下载描述文件**”（带红色角标），点它 → 安装 → 输锁屏密码 → 会警告“未签名”，点“仍然安装”。
   （如果设置首页没有这一项：设置 → 通用 → VPN与设备管理 里找“小于的考研课表”→ 安装。）
3. 安装完成后主屏幕出现“考研课表”图标（可能在最后一屏或 App 资源库里，往右滑到底找，或桌面下滑搜“考研”），点开直接进线上课表——**发布任何更新，打开就是最新版**，无需重装。
4. 想删就长按图标删除，或在 设置 → VPN 与设备管理 里移除描述文件。

页面页脚也放了同一个安装链接；不装描述文件的话，Safari 里“添加到主屏幕”效果相同（apple-touch-icon 已配好）。

## 运行

直接用任意静态文件服务器打开 `index.html` 即可。页面无外部字体依赖；页面在前台时每秒更新时钟，切到后台会停止定时器，回来后恢复，避免无意义刷新。

## 验收原则

- 数学：先闭卷独做，再按概念 / 计算 / 思路记录错因；次日或 48 小时回做同类题。
- 436：按手头资料顺序核对内容单元；合书输出框架，短答和计算必须完整落笔。
- 英语：每题找证据句，记录定位 / 词义 / 句法 / 逻辑 / 干扰项错因；单词遮住释义主动回想。
- 计划不是“保上岸”承诺。它的容错来自明确的最小补量、固定睡眠边界和每周/月底用真实数据回调，而不是继续堆学习时长。
